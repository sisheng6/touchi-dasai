# 偷吃大赛

**在线试玩（电脑）：https://sisheng6.github.io/touchi-dasai/**

**手机竖屏版：https://sisheng6.github.io/touchi-dasai/mobile/**（用手机浏览器打开；模型是 Meshy 智能拓扑专门生成的低面数版本）

一款第一人称 3D 网页小游戏：在动漫风的教室里，趁老师不注意偷吃零食。下课前把饱腹吃到 100 就算赢。

## 怎么玩

- 按住**空格**（或右下角按钮）偷吃，松开就停。
- **← →**、数字 **1–8** 或鼠标滚轮换食物；拖动鼠标环顾四周。
- 老师背过身的时候吃。听到咳嗽就赶紧松手。
- 凑齐食物组合可以解锁新的食物。
- 按 **Esc / P** 暂停，可以查看规则。

推荐用电脑上的 Chrome 或 Edge 打开，记得开声音。第一次加载模型要等几秒。

## 制作

- 3D 模型：Meshy（Image to 3D、自动绑骨、动画库）
- 引擎：Three.js
- 图片：GPT Image（Codex）
- 骨骼修正：Blender
- 编程：Claude Code
- 音效和 BGM：Uppbeat，来源见 [audio-credits.md](audio-credits.md)
